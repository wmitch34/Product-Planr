Product Planr UI

Scaffolded Vite + React app.

To run locally:

1. cd product-planr-ui
2. npm install
3. npm run dev

This initial implementation includes an in-memory interactive Graph component (src/components/Graph.jsx) using Tailwind for styling. It supports adding nodes, dragging nodes, and connecting nodes by double-clicking a source then clicking a target (or clicking when connecting). Persistence and backend integration can be added next.
